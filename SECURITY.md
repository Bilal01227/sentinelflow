# Security policy

## Scope

SentinelFlow currently processes offline network-flow summaries. It does not capture traffic, execute payloads, exploit hosts, or change network controls.

## Reporting a vulnerability

Please do not publish sensitive exploit details in a public issue. Use GitHub's private vulnerability reporting feature for this repository where available. Include affected version/commit, impact, reproduction steps, and a proposed mitigation. Do not include real customer traffic or secrets.

## Supported versions

Only the latest release is supported while the project is in alpha.
