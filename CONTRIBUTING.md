# Contributing

Thanks for helping improve SentinelFlow. Keep contributions reproducible, reviewable, and safe.

1. Open an issue before substantial changes so the design can be discussed.
2. Keep pull requests focused and explain the problem, design, and trade-offs.
3. Add tests for new behaviour and regression cases.
4. Run `ruff check .` and `pytest` before submitting.
5. Never commit credentials, real packet captures, customer data, or unredacted IP inventories.
6. Do not describe synthetic metrics as real-world detection performance.
7. Document feature limitations and any changes to the input schema.

By submitting a contribution, you agree that it may be distributed under the repository's MIT license.
